# 双截龙 · 重生 / Double Dragon Reborn

浏览器里的 FC 清版动作游戏。复刻 Technos Japan 1988 年那版《双截龙》的核心机制，
外加一套自己的成长系统。TypeScript + Canvas 2D，**仓库里没有一个二进制资源**——
没有图片、没有音频、没有模型，全部程序化生成。

**在线试玩：** https://opc007.github.io/double-dragon-reborn/

```
npm install
npm run dev        # 开发
npm run build      # 构建
npm run test       # 89 个单测
npm run smoke      # 无头浏览器跑真游戏 + 截图（验收用）
```

## 操作

| 键 | 动作 |
|---|---|
| `W` `A` `S` `D` | 移动 / 上下切纵深 |
| `J` | 拳 |
| `K` | 脚 |
| `L` | 跳 |
| `Q` | 双截奥义（气满时） |
| `↓` + `J` / `K` | 上勾拳 / 回旋踢（Lv2 解锁） |
| 空中 + `K` | 飞踢（Lv3） |
| 抓住敌人 + `J` / `K` | 抓发膝撞 / 过肩摔（Lv4） |
| 敌人绕到背后 + `J` | 霸王肩（Lv6） |
| 空中 + `J` | 旋风腿（Lv7） |
| `ESC` / `P` | 暂停 |

**双人同屏：** P2 用 `方向键` + `.` `,` `/`

**核心操作不是按键，是"走过去"。** 直接走进敌人身体就会自动抓住他——
这是原作最关键的一条手感，也是整个战斗系统的入口。

## 复刻了什么

| 机制 | 说明 |
|---|---|
| **双层纵深** | 三个深度带。不在同一个深度带就打不到人——走位和输出互相牵制 |
| **抓投** | 走进去自动抓。抓住后能膝撞、摔投；**把敌人甩出去撞到别人，两边一起重伤** |
| **缴械夺武器** | 打掉敌人手里的球棒/刀/鞭，捡起来用。扔出武器杀伤力更大 |
| **扔出屏幕** | 被摔飞出画面边界 = 直接退场。清场的省力打法 |
| **深坑** | 地面有坑，踩上去掉下去直接死。坑都放在波次之间的通行段，跳过去就行 |
| **7 级成长** | 原作最独特的设计：打怪攒经验，每 1000 经验升一级，**逐级解锁新招** |
| **四关** | 贫民窟 → 废弃工厂 → 城郊林道 → 敌方基地 |
| **双 BOSS 收尾** | 威利（机枪）之后是**亲哥哥吉米**——FC 版招牌，街机版留给双人互打 |
| **清版推进** | 走到触发点镜头锁死，必须清完才能往前。分批进场，同屏最多 2 个 |
| **计时器** | 99 起步，每清一波补满 |
| **三条命** | 死一次回到关卡头，等级和经验保留；通关补一条命（上限 5） |

敌人也是原班人马：威利姆斯、洛珀、琳达、阿波波，
关底是博洛斯、钦泰、威利、吉米。

## 加了什么

原作没有、这次新加的：

1. **气 / Chi 系统** —— 命中攒气，气满放全屏「双截奥义」。
   给了重武器一个"攒→爆发"的节奏，也让打不出 combo 的场面有解法。
2. **道场养成** —— 局外元系统。打怪攒铜钱，铜钱换永久强化（体力/伤害/移速/获气/收徒）。
   原作的成长是"一局之内"的，死了就没了；这里让"再来一次"有个盼头。
3. **收徒弟** —— 可带一名 AI 师弟同行。他跑的是和玩家同一套代码，
   也会升级、也会被打倒，不会有"AI 会一招玩家不会"的割裂感。
4. **深坑 + 扔出屏幕** 的组合拳，让清场效率有了上限之外的解法。
5. **渲染回归** —— 无头浏览器把每一关、每个 BOSS 截下来，CI 里能看。
6. **机器人试玩平衡** —— 见下。

---

## 平衡是量出来的，不是调出来的

`npm run balance` 会让一个会打的 bot 跑 200 局全流程，输出通过率、各关用时、
死亡分布。调数值之前先看这张表，比手感靠谱。

当前（白手、无道场强化、200 局）：

```
全通率         100.0%
平均时长       5.2 分钟
各关用时       贫民窟 53s / 工厂 77s / 林道 58s / 基地 122s
平均死亡       工厂 1 次 / 基地 1 次
```

这套表抓出过五个真实的 bug，全部属于"不报错、不崩溃、就是卡住不动"：
波次被跳空、玩家被击退后永久卡关、敌人受击后卡在硬直、BOSS 完成判定被门控挡住、
镜头锁死把玩家挤出画面。都固化成了回归测试。

## 技术栈

| | |
|---|---|
| 渲染 | Canvas 2D，逻辑分辨率固定 256×240（NES 原生），整数倍放大 |
| 语言 | TypeScript `strict` |
| 构建 | Vite 5 |
| 测试 | Vitest（89 个单测） |
| 渲染自测 | Playwright + headless Chromium |
| 美术 | 100% 程序化，**零二进制资源** |

**依赖只有 4 个**：`vite`、`typescript`、`vitest`、`playwright`。
不要引入美术资源管线——整个游戏没有图片和音频文件，
`clone` 下来 `npm install && npm run dev` 就能跑，仓库永远只有几十 KB。

角色是用「骨架 + 关节角度」画的：每个姿态只描述手肘/膝盖的角度，
渲染时按角度算关节位置再描边填充。这样任意动作组合都能出合理的一帧，
加新招式不用补美术资源。

## 目录

```
src/
  main.ts             入口：画布装配 + 固定 60Hz 主循环
  core/               常量 / 数学 / 带种子的 PRNG / 输入 / WebAudio 音效与 BGM
  data/               招式表、武器表、敌人图鉴、关卡数据（纯数据）
  entities/           Fighter（战斗基类）/ Player / Enemy / Projectile
  systems/            World（一关的完整模拟）/ dojo（元进度）/ aiPad（师弟 AI）/ bot（试玩机器人）
  render/             程序化像素角色 / 程序化背景 / HUD
  game/Game.ts        顶层状态机 + 各个画面
scripts/
  smoke.mjs           无头浏览器跑真游戏 + 逐关截图
  balance.ts          机器人试玩平衡报告
```
